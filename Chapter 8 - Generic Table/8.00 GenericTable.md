# Chapter 8 - Generic Table - WIP(作業中)

この章では、実際の DLL の一部をリバースします。取り上げる DLL は NTDLL.dll です。かなり大きな DLL なので、全体をリバースはしません。Generic Table(GT)関数に焦点を当てます。generic table 関数を選んだのは、半ばドキュメント化されている(そのため結果を確認できる)こと、関数が複数あること、さまざまな概念を扱っていることが理由です。

>generic table のデータ構造は公式にドキュメント化されていますが、学習のためには、そのドキュメントを見ないようにしてください。
