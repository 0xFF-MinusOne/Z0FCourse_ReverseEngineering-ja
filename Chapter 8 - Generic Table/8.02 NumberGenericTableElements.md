# 8.02 NumberGenericTableElements

初期化関数を見て、基本的なレイアウトがおおよそ分かりました。次は、おそらくより単純な関数を見ながら、簡単に得られる情報をできるだけ集め、その後でより複雑な関数に取り組みましょう。`RtlNumberGenericTableElements` から始めます。

この関数がどう動作しうるか考えてみてください。1つの可能性は、関数がテーブルをループするというものです。もう1つの可能性は、テーブルにその要素数を保持する要素があるというものです。見てみましょう。

`RtlNumberGenericTableElements` の逆アセンブルは次のとおりです。

```asm
MOV EAX, DWORD PTR DS:[RCX + 0x24]
RET 
```

この関数は非常に単純ですが、とても役に立ちます。パラメータを1つ取り、それは generic table です。関数は、テーブルのオフセット +0x24 にあるものを返します。ただし、少し問題があります。+0x24 は8バイトの倍数のオフセットではありません。これは、各メンバーが8バイトであるという私たちの考えが間違っているかもしれないことを意味します。また、メンバーの一部だけにアクセスしているということかもしれません。一部のバイトにはある情報が入っていて、残りのバイトには別の情報やデータが入っているのかもしれません。

通常は、これは有効なオフセットで、4バイトの要素があり、すべての要素が8バイトとは限らないと仮定するほうが安全です。もし間違っていたら、きっと分かります。

予測したテーブルのレイアウトを更新しましょう。

```c
struct Table{
    UNKNOWN Member1;
    UNKNOWN_PTR Member2;
    UNKNOWN_PTR Member3;
    UNKNOWN_PTR Member4;
    UNKNOWN Member5;
    DWORD NumOfElements;
    UNKNOWN Member7;
    UNKNOWN Member8;
    UNKNOWN Member9;    
};
```
