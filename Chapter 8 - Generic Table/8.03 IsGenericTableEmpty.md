# 8.03 IsGenericTableEmpty

次は `RtlIsGenericTableEmpty` を見てみましょう。これも、リバースしやすく、貴重な情報が得られるかもしれない関数です。

ここでも、どう動作しうるか予測してみましょう。テーブルには、空でないときに設定または変更されるメンバーがあるのかもしれません。もう1つの可能性は、先ほど見つけた、テーブルの要素数に関するメンバー(`NumOfElements` と呼んでいるもの)を使うというものです。

`RtlIsGenericTableEmpty` の逆アセンブルは次のとおりです。

```asm
CMP QWORD PTR DS:[RCX], 0x0
SETE AL
RET 
```

ここでも、非常に単純な関数です。

* テーブルの最初の要素(RCX で渡される)を 0 と比較します。
* `SETE` は、ゼロフラグ(ZF)がセットされていればオペランドのバイトを 1 に設定し、そうでなければオペランドを 0 に設定します。つまり、RCX がゼロなら AL が 1 に設定され、関数は AL を返します。

>見たことのないアセンブリ命令に出会うのはよくあることなので、オンラインで答えを調べることを恐れないでください。

この関数は、最初のメンバーがゼロかどうかを確認し、ゼロなら true を返します。そうでなければ false を返します。このことから、generic table の最初のメンバーは、テーブルに要素があるときはゼロでないと分かります。

結局、あまり多くは分かりませんでしたが、少しでも役に立ちます。この情報を予測に加えておきましょう。

```c
struct Table{
    QWORD Member1;  //Nonzero when the table has elements.
    QWORD_PTR Member2;
    QWORD_PTR Member3;
    QWORD_PTR Member4;
    QWORD Member5;
    DWORD NumOfElements;
    QWORD Member7;
    QWORD Member8;
    QWORD Member9;    
};
```
