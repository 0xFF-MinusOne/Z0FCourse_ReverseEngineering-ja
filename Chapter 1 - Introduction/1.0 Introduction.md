## 前提知識

**必読:** コンピューターサイエンスの知識がまったくない場合は、この YouTube のプレイリストを見てください。私はこのプレイリストが大好きです。ハーバード大学のコンピューターサイエンス入門です:  
[https://www.youtube.com/playlist?list=PLhQjrBD2T381L3iZyDTxRwOBuUt6m1FnW](https://www.youtube.com/playlist?list=PLhQjrBD2T381L3iZyDTxRwOBuUt6m1FnW)

* C/C++ をよく理解していること。
* Java や C# などの言語でのオブジェクト指向プログラミングの経験。
* ポインタ、配列、構造体/クラス、継承などを理解していること。
* **強く推奨**: x86 または x64 のアセンブリプログラミング。できれば x64 Windows のもの。

**C を学ぶ:**  
[learn-c.org](https://www.learn-c.org/)  
[Beej Jorgensen Guide to C](https://beej.us/guide/bgc/html/split/)  

**C++ を学ぶ:**  
[learncpp.com](https://www.learncpp.com/)

**C++ の経験が少しある場合:**
