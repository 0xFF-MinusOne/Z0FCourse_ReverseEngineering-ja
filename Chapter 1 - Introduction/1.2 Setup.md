# 1.2 環境構築

この講座は 64 ビット Windows を中心に扱いますが、32 ビットについても少し触れます。注: この講座では x32 と x86 はどちらも 32 ビットを指します。

## オペレーティングシステム

64 ビットの Windows OS が必要です。必要であれば仮想マシン(VM)を使ってもかまいません。セキュリティ上の理由から、通常は VM を使うのが最善ですが、マルウェアの章までは気にする必要はありません。リバースエンジニアリングを自分の生活の一部にするつもりなら、いずれにせよリバース用の VM を用意したくなるでしょう。VM があれば、リバース対象のソフトウェアをより確実に隔離できます。プログラムのネットワーク通信、ディスクの使用、レジストリの変更などを分析するときに、これは非常に役立ちます。また、何か壊してしまっても VM を元に戻せます。繰り返しますが、この講座では VM は必要ありませんが、将来的には用意することをお勧めします。

## リバース用ツール

ほとんどのソフトウェアは、好きなものに置き換えられます。私が使うソフトウェアは次のとおりです(すべて無料です):  

### 必須

* [**Microsoft Visual C++ Redistributable**](https://aka.ms/vs/16/release/vc_redist.x64.exe) を入れると、私が提供するプログラムや DLL を実行できます。できれば、Visual Studio を「C++ によるデスクトップ開発」ワークロード付きでインストールしてください。
* [**x64dbg**](https://x64dbg.com/)(x32dbg も付属します)。[xAnalyzer](https://github.com/ThunderCls/xAnalyzer) プラグインも使います。必須ではありませんが、お勧めします。
* [**dnSpy**](https://github.com/0xd4d/dnSpy)(推奨)または [ILSpy](https://github.com/icsharpcode/ILSpy)(終盤の .NET のリバースで使います)。

### 任意

ここに挙げるソフトウェアはこの講座では使いませんが、将来使いたくなるかもしれません。

* **強く推奨:**
  * [**Ghidra**](https://ghidra-sre.org/)(Java JRE と JDK が必要です)。
  * 「C++ によるデスクトップ開発」入りの [**Visual Studio**](https://visualstudio.microsoft.com/)。「.NET デスクトップ開発」も入れることをお勧めします。
* [**HxD**](https://mh-nexus.de/en/hxd/)(16 進エディター)
* [**Sysinternals Suite**](https://docs.microsoft.com/en-us/sysinternals/downloads/sysinternals-suite)(Windows を分析するさまざまなツール)。
* [**Dependency Walker**](http://www.dependencywalker.com/)(Visual Studio に付属する "DUMPBIN" の GUI 版の代わりとして使えます)。

**このソフトウェアをいつインストールするかは自由です。使い始めるのは第 4 章からです。**

見てのとおり、IDA Pro はありません! Ghidra が登場した今、IDA Freeware や Pro を使う理由はあまりありません。IDA Pro のほうが(私の意見では)優れていますが、Ghidra のように無料ではありません。それどころか、かなり高価です。IDA が好みなら、使ってもかまいません。私はけちなので使いません。

ほかにも、いつか見てみるとよいソフトウェアとして、Hopper、Radare、Binary Ninja があります。このうち無料なのは Radare だけです。Hopper には無料版がありますが、一定の時間しか使えません。
