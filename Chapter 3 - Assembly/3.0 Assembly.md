# Chapter 3 - Assembly(アセンブリ)

この章は、アセンブリ言語の短期集中講座、または復習の役割を果たします。この講座は x64 アセンブリを中心に扱います。これは決してアセンブリの完全な講座ではないので、先に進む前に、アセンブリの講座を一通り受けておく必要があります。高度なアセンブリの知識は要りませんが、基本的なアセンブリプログラムを書ける必要はあります。
