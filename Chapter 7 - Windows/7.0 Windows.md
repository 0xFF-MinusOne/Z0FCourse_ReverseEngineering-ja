# CURRENTLY IN DEVELOPMENT (Chapter 7 - Windows)(現在開発中)

この章では、Windows OS の基本的な内部動作の一部を取り上げます。ほとんどのトピックは基本的なレベルまでしか扱わず、必要な情報だけを扱います。Windows OS には学ぶことが非常に多く、このコースに収めるにはあまりにも多すぎます。詳細を知りたい場合は、[「Windows Internals」の書籍](https://www.amazon.com/Windows-Internals-Part-architecture-management/dp/0735684189)が素晴らしい資料になります。学ぶことが多いと言ったのを思い出してください。この書籍にはパート1とパート2があり、それぞれ約800ページあります。

Windows は巨大なので、このコースでは必要なこと、または知っておくと良いことだけを扱います。さらに学ぶためのリンクは数多く提供します。
